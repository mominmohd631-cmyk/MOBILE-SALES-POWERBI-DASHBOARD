# Mobile Sales Dashboard – Power BI

Project Overview:
This project presents an interactive Mobile Sales Dashboard built using Microsoft Power BI to analyze mobile sales performance.

Tools Used:
- Microsoft Power BI
- Power Query
- DAX
- Excel

Dashboard Features:
- Total Sales, Total Quantity and Total Transactions
- Average Sales Analysis
- Monthly Sales Trends
- Sales by Mobile Model
- Transactions by Payment Method
- Customer Ratings Analysis
- MTD (Month-to-Date) Analysis
- Same Period Last Year Analysis
- Interactive filters and slicers

Project Files:
- "Mobile_Sales_Dashboard.pbix" – Power BI dashboard file
- "Dashboard.png" – Main dashboard screenshot
- "MTD.png" – MTD analysis screenshot
- "Same_Period_Last_Year.png" – Year-over-year analysis screenshot

Objective
To analyze mobile sales data, identify sales trends and provide useful insights through an interactive dashboard.
